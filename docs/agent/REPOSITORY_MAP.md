# Mapa do Repositório

| Local | Uso |
| --- | --- |
| `src/app` | App Router, páginas, layouts e APIs |
| `src/features` | domínios de negócio e seus testes |
| `src/components/ui` | primitives shadcn e variantes compartilhadas |
| `src/components/unlumen-ui` | feedback visual e estados compartilhados |
| `src/shared`, `src/utils` | infraestrutura, auth, banco, async e validação |
| `drizzle` | migrations versionadas |
| `tests/e2e` | fluxos de navegador Playwright |
| `apps/browser-extension` | CorreTop Assistant MV3 |
| `services` | serviços isolados de integração |
| `docs` | regras, decisões, planos e runbooks |

O mapa estático completo é regenerável em `graphify-out/` e serve somente para
orientação; o código e os contratos versionados prevalecem.
