# Glossário de Engenharia

| Termo | Definição |
| --- | --- |
| Engineering Harness | conjunto versionado de contexto, políticas, scripts e gates que torna execução repetível e verificável. |
| Contexto nível 0 | leitura curta obrigatória para qualquer tarefa. |
| Manifest de contexto | mapeamento de domínios, palavras-chave e documentos que orienta descoberta sob demanda. |
| Gate de aceite | verificação objetiva necessária antes de declarar uma tarefa concluída. |
| Diagnóstico | checker que reporta risco, mas ainda não bloqueia pela dívida preexistente. |
| Evidência | saída versionável ou reproduzível de comando/teste que sustenta uma afirmação de entrega. |
| Registro de implementação | documento curto que liga objetivo, arquivos, decisões, validações, riscos e rollback. |
