# Política de Contexto

O contexto é carregado por necessidade, não por volume. O nível 0 tem o contrato operacional; o nível 1 é escolhido por palavras-chave, caminhos alterados e domínio; o nível 2 explica decisões anteriores; o nível 3 é reservado a incidentes.

O comando `agent:context` produz uma lista ordenada e a razão de cada documento. Se um arquivo relevante não estiver no manifest, atualize o manifest no mesmo ciclo. Não resuma regras críticas somente em prompt: registre-as no documento canônico.
