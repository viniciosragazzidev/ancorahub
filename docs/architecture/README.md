# Arquitetura

Este diretório contém a visão operacional de módulos, decisões e diagramas. O mapa de
módulos serve para descoberta de contexto; decisões duradouras permanecem em
`docs/decision-log.md` e ADRs. Diagramas descrevem relações, não substituem contratos
tipados ou o código.

Atualize um módulo quando seu limite, dependência ou invariante mudar. Crie decisão
quando a alteração for difícil de reverter, surpreendente e resultado de trade-off real.
