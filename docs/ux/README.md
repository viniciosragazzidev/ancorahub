# UX e Redesign do Produto

Este diretório é a fonte de verdade para qualquer trabalho visual, de navegação ou
de arquitetura da informação no CRM. Ele substitui o design system documental
anterior.

## Leitura obrigatória

1. [Contrato de Redesign](./UX_REDESIGN_CONTRACT.md)
2. [Controle de Execução](./UX_REDESIGN_CONTROL.md)
3. Regras de domínio e permissões aplicáveis em `docs/business-rules.md` e
   `docs/decision-log.md`.

## Regra de operação

Não redesenhar telas em lote. Cada etapa começa por evidência do código e do fluxo
real, define a hierarquia e os estados necessários, altera uma superfície coesa e
registra a validação no Controle de Execução.

O documento de controle informa sempre a etapa atual, a próxima ação permitida e os
critérios de saída. Ao encerrar uma etapa, o agente deve atualizá-lo antes de iniciar
a próxima.
