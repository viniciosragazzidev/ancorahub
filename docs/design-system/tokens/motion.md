# Tokens de Motion

Nenhum valor de duração, easing, distância ou stagger foi confirmado em `design.md`.

| Token | Estado | Regra |
|---|---|---|
| `motion.duration.*` | MISSING | usar somente tokens centralizados já existentes até DG-007. |
| `motion.ease.*` | MISSING | não criar curva local. |
| `motion.distance.*` | MISSING | não criar deslocamento local. |

`prefers-reduced-motion` é obrigatório pela norma do projeto.
