# Tokens de Espaçamento

Base confirmada: 4 px.

| Token | Valor | Propósito | Usar | Não usar |
|---|---:|---|---|---|
| `space.1`–`space.20` | 4, 8, 12, 16, 20, 24, 28, 32, 36, 40, 48, 64, 80, 96 px | ritmo vertical/horizontal | valores da escala | valores intermediários arbitrários. |
| `layout.max` | 1200 px | largura máxima de referência | páginas editoriais aprovadas | assumir como grid operacional sem decisão. |
| `layout.section` | 96 px | separação de seção | referência de landing | tabela/lista densa sem adaptação. |
| `layout.card.padding` | 24 px | card de feature | card correspondente | todo Card existente automaticamente. |
| `layout.gap` | 12 px | gap de elementos | grupo compacto | substituir escala inteira. |
