# ANALYTICS_PAGE

Use para compreender métricas e tomar decisões, não apenas exibir gráficos.

## Composição

Título com escopo/período → até três prioridades → visualização com definição e origem → comparação contextual → tabela/drill-down acionável.

- Período, filtros e unidade são persistíveis na URL quando definem a leitura.
- Cada métrica informa definição, recorte e quando foi atualizada.
- Gráficos têm alternativa tabular ou textual; cor não é a única codificação.

## Estados obrigatórios

loading, sem dados no período, filtro inválido, dado parcial/sincronizando, erro, sem permissão e indisponível.

## Não usar

Não apresentar métricas fixas, sem origem ou sem ação possível.
