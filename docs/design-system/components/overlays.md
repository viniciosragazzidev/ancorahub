# Overlays

Implementações oficiais: Dialog, Drawer, Sheet, Popover, Tooltip e DropdownMenu em `src/components/ui/`.

Use Dialog para confirmação e formulários curtos; Drawer para contexto ou edição extensa; Popover/Tooltip para conteúdo breve ancorado. Não criar `Modal`, `PopupModal` ou confirm dialogs locais. A escolha final Sheet versus Drawer e a escala de camadas aguardam DG-011.
