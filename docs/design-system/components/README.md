# Template de Componente

Use este template ao documentar ou evoluir um primitive/composite.

```md
# Nome do componente

## Purpose
## Anatomy
## Variants
## States
## Behavior
## Accessibility
## Content
## Responsive behavior
## Tokens
## Do
## Don't
## Examples
## Related gaps
```

Não inclua regras de negócio, dados de tenant, permissões ou fluxo comercial. Esses itens pertencem à feature que compõe o componente.
