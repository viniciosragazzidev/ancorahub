# Taxonomia de Overlays

- **Dialog**: confirmação, interação curta ou formulário pequeno e modal.
- **Drawer**: detalhe contextual ou edição extensa.
- **Popover**: conteúdo breve ancorado ao trigger.
- **DropdownMenu**: lista de ações.
- **Tooltip**: ajuda breve, nunca única fonte de informação essencial.
- **Sheet**: compatibilidade técnica legada; não introduzir como conceito concorrente. Novos consumidores escolhem Drawer quando a superfície é lateral.

Essa taxonomia resolve DG-011. Foco, Escape e portal são responsabilidade das primitives existentes; o layout consumidor decide responsividade.
