# Runbooks

Runbooks são procedimentos operacionais para falhas ou tarefas repetíveis que exigem
ação humana. Cada runbook deve declarar gatilho, pré-requisitos, passos seguros,
validação, rollback e contatos/responsável. Não registre segredos, tokens ou dados de
leads. Incidentes recorrentes devem apontar também para `docs/agent/KNOWN_ISSUES.md`.
